## Projects

| | What it is | Get it |
|---|---|---|
| **[keelOS](https://github.com/keelos-dev/keelOS-releases)** | A virtualization host for the one server at home or in a small office, on FreeBSD, bhyve and ZFS. **Restart the host, your VMs carry on**: a ~100 KB hypervisor holds the guests while the host system upgrades and reboots. Passthrough, Windows 11 with vTPM and Secure Boot, web UI + CLI + API. | [ISO releases](https://github.com/keelos-dev/keelOS-releases/releases) · [Quickstart](https://keelos.dev/quickstart/) |
| **[hyperMAC](https://github.com/keelos-dev/hyperMAC)** | Windows 11 on your Mac in three clicks. bhyve ported to Apple Silicon plus Virtualization.framework, with a built-in RDP server for the Mac's own desktop and its VMs. Free and open source (MIT). | [Download for macOS](https://github.com/keelos-dev/hyperMAC/releases) |
| **[kRDPclient](https://github.com/keelos-dev/kRDPclient-releases)** | The console client for keelOS VMs (Windows x64): RDP with sound, USB forwarding and GPU-encoded video. Every keelOS host also serves a pre-configured copy. | [Windows builds](https://github.com/keelos-dev/kRDPclient-releases/releases) |
